# 종합보고서 본문 템플릿 (`state/notes/11_body.md`)

> 형식: Narrative Literature Review. 본문은 **연구 간 비교와 본 연구에 대한 함의** 중심. 논문별 요약은 부록(07)으로.
> Ⅷ 참고문헌·부록 목록은 렌더러가 자동으로 붙이므로 본문에 쓰지 않는다. 권고 분량 10~15쪽.

```markdown
# 선행연구 종합보고서 — <연구주제>

> 작성: Adaptive Literature Review Agent · Research Profile vN · 작성일 YYYY-MM-DD
> 본 보고서는 서술적 문헌검토이며 체계적 문헌고찰(Systematic Review)이 아니다. 검토 범위: Core N편, Extended M편.

## Ⅰ. 조사 개요
- 연구주제·질문 / 조사 목적·범위
- 분야별 우선 학술출처 선정 근거·Source ID (상세: 01a, 부록 E) — 우선 출처는 검색 순서용이며 선정 조건이 아님을 명시
- Stage A(우선 출처)/B(제한 없는 인용망)/C(독립·광역) 검색 DB·검색식·필터·포함·제외 조건 (상세: 04)
- 검색·선별 규모: 수집 X건 → 후보 검토 Y건 → Core N편 (목표 20편 대비 부족 시 사유)

## Ⅱ. 핵심문헌 선정 결과
- Seed 3편과 선정 이유 [P-...]
- 핵심논문 우선순위 요약 — 아래 자리표시자에 Core 전체 순위표가 자동 삽입된다(역할별 순위·기준별 근거는 부록 F)

{{RANKING_TABLE}}

- 상위 문헌을 먼저 읽고 인용해야 하는 이유, 평가보류 문헌과 그 사유
- 검색 모드(국내/해외/통합)와 국내외 수집·선정 구성(해당 시)
- Stage A/B/C별 발견·선정 규모, 우선 출처 밖에서 선정된 중요 문헌과 이유, Stage C에서만 발견된 문헌
- 역할·연도·분야 분포, 전문 확보 현황(전문 a편 / 초록 기반 b편)
- 선정의 한계(언어 편중, 인용망 편향 등)

## Ⅲ. 이론적 배경 분석
- 주요 개념·이론의 계보, 공통·대립 관점, 적용 조건 — 주장마다 [P-..; E-..]

## Ⅳ. 방법론 및 변수·지표 비교
| 연구 | 설계 | 데이터·표본 | 핵심 변수·측정 | 식별전략 | 장단점 |
(표의 각 행에 P-ID)

## Ⅴ. 유사 실증사례 및 주요 연구결과
- 결과 방향·크기를 원 연구의 단위·표본·모형 조건과 함께. 서로 다른 연구의 효과크기를 근거 없이 직접 비교·평균하지 않는다.
- 일치·상충 결과와 상충 원인 **후보**

## Ⅵ. 연구계획서 연계·인용 활용계획
- 장·절별 핵심 활용 문헌 요약 (상세: 10)

## Ⅶ. 연구공백·한계·확장계획
- 검토 범위 내 부족 영역 **후보** [G-...]; 원문 미확보 문헌이 결론에 미치는 영향; 추가 탐색 우선순위
- 본 검토의 한계: DB 커버리지, 언어, 검색일, 초록 기반 분석 비중
```

## 작성 규칙 체크리스트
- [ ] 연구 간 종합 주장마다 `[P-xxx]` (가능하면 `; E-xxx-yy`)
- [ ] 직접 인용은 `VERIFIED_FULLTEXT` 근거의 짧은 발췌만, 따옴표 + 근거 ID
- [ ] 초록 기반 문헌은 "초록에 따르면" 등으로 수준을 밝힘
- [ ] 인과/상관, 유의/비유의, 저자 주장/재인용, 프리프린트/출판본 구분
- [ ] '연구가 없다' 대신 '본 검토 범위에서 확인되지 않음'
- [ ] DOI·서지를 본문에 직접 쓰지 않음(렌더러가 DB에서 생성)
- [ ] 학술지 권위·`is_core`·`listed_in`을 논문 품질 근거로 쓰지 않음
- [ ] 우선 출처 검색이 비용·시간을 줄였다고 단정하지 않음(04의 실측 호출량으로만 서술)
- [ ] 중요도 순위를 '이 연구계획 기준의 활용 우선순위'로 설명하고, 학술적 가치 서열처럼 쓰지 않음
- [ ] KCI·해외 인용수를 비교·합산하지 않음, KCI 학술지 인용지수를 논문 인용수로 쓰지 않음
